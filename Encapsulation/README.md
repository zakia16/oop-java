This module covers two critical concepts in Java development: enforcing data security and abstraction through Encapsulation, and managing dynamic collections of objects using Java's built-in ArrayList class.

Basic Principles of OOPs
Object-oriented programming is mainly based on four principles:
Encapsulation
Abstraction
Inheritance
Polymorphism

Encapsulation
Encapsulation combines data and the methods that work on it within a single unit. It can also restrict direct access to certain data.

For example, a bank account can prevent users from directly changing its balance and provide methods for depositing or withdrawing money.
